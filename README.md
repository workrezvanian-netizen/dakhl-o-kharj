# دخل و خرج — راهنمای انتشار (وضعیت فعلی: آماده آپلود)

این پروژه دو تا ریپازیتوری جداست. فایل‌های هرکدوم پایین‌تر جدا مشخص شده.

## ریپازیتوری ۱ — سایت اپ (GitHub Pages)
این فایل‌ها رو توی ریپازیتوری سایت (همونی که GitHub Pages ازش منتشر می‌شه) آپلود کن،
جایگزین نسخه‌های قبلی بشن:
- `index.html`
- `style.css`
- `script.js`   ← این نسخه از قبل به آدرس Worker وصل شده، دیگه نیازی به ویرایش دستی نیست
- `manifest.json`
- `sw.js`
- پوشه‌ی `icons` (دو فایل PNG داخلش)

بعد از آپلود، چند دقیقه صبر کن تا GitHub Pages نسخه‌ی جدید رو منتشر کنه.

## ریپازیتوری ۲ — بک‌اند Worker (dakhl-o-kharj روی Cloudflare)
این فایل‌ها رو توی ریپازیتوری Worker آپلود کن (جایگزین فایل‌های قبلی بشن):
- `worker.js`      ← کد اصلی بک‌اند
- `wrangler.toml`  ← تنظیمات دیپلوی + اتصال KV (دیگه لازم نیست از داشبورد دستی Binding اضافه کنی)

بعد از Commit، Cloudflare خودش دوباره دیپلوی می‌کنه. توی تب **Deployments** می‌تونی پیشرفتش رو ببینی،
و توی تب **Bindings** باید `DNK_KV` رو زیر Connected Bindings ببینی.

## تحلیل هوشمند (Gemini)
تحلیل هوشمند از Gemini API گوگل استفاده می‌کنه. برای فعال‌سازیش:
1. برو به [aistudio.google.com/apikey](https://aistudio.google.com/apikey) و یه کلید API رایگان بساز.
2. توی ترمینال، از پوشه‌ی همون ریپازیتوری Worker این دستور رو بزن:
   ```
   wrangler secret put GEMINI_API_KEY
   ```
   و کلیدت رو وقتی خواست پیست کن.
3. همین — بعد از این، دکمه‌ی «تحلیل هوشمند» توی اپ باید کار کنه.

## نحوه‌ی کارکرد همگام‌سازی
- هر کاربر یه «کد همگام‌سازی» ۶ رقمی می‌سازه (از تب تنظیمات اپ).
- با وارد کردن همون کد روی دستگاه دیگه، اطلاعات دو طرف با هم یکی می‌شن.
- کد فقط یه شناسه‌ی ساده برای پیدا کردن داده روی سرورـه، نه رمز عبور — یعنی هرکسی کد رو داشته باشه به همون داده دسترسی داره. برای استفاده‌ی شخصی/خانوادگی کافیه.

## نصب روی گوشی
- آیفون: سافاری → دکمه‌ی اشتراک‌گذاری → Add to Home Screen
- اندروید: کروم → منو → Add to Home screen / Install app

## بعد از آپلود هر دو ریپازیتوری
1. سایت رو باز کن، برو به تب تنظیمات.
2. دکمه‌ی «ساخت کد جدید» رو بزن.
3. اگه بالای صفحه نوشت «متصل» (نه «محلی»)، یعنی همگام‌سازی با Worker برقراره.
4. اگه بازم نوشت «محلی» یا خطا داد، اسکرین‌شات بفرست تا بررسی کنیم.
