# دخل و خرج — راهنمای انتشار

## بخش ۱ — انتشار خود اپ (GitHub Pages)
1. یک ریپازیتوری جدید توی گیت‌هاب بساز (مثلاً `dakhl-o-kharj`).
2. همه‌ی این فایل‌ها رو (به‌جز `worker.js`) با کشیدن و رها کردن (drag & drop) توی صفحه‌ی ریپازیتوری آپلود کن:
   - `index.html`
   - `style.css`
   - `script.js`
   - `manifest.json`
   - `sw.js`
   - پوشه‌ی `icons` با هر دو فایل داخلش
3. برو به Settings → Pages → از قسمت Branch گزینه‌ی `main` رو انتخاب کن و Save بزن.
4. بعد از چند دقیقه آدرس اپ فعال می‌شه، چیزی شبیه:
   `https://USERNAME.github.io/dakhl-o-kharj/`

بدون انجام بخش ۲، اپ کامل کار می‌کنه ولی فقط روی همون گوشی — چون هنوز به بک‌اند وصل نشده.

## بخش ۲ — همگام‌سازی بین دستگاه‌ها (Cloudflare Worker)
1. وارد داشبورد Cloudflare بشو → Workers & Pages → Create → یک Worker جدید بساز.
2. کد فایل `worker.js` رو کامل کپی کن و توی ادیتور Worker (Quick Edit) جایگزین کد پیش‌فرض کن، بعد Deploy بزن.
3. برو به تنظیمات همون Worker → KV → یک KV Namespace جدید بساز (مثلاً به اسم `DNK_KV`).
4. توی تنظیمات Worker، تب Bindings، یک Binding از نوع KV Namespace اضافه کن:
   - Variable name: `DNK_KV`
   - Namespace: همونی که ساختی
5. آدرس Worker (چیزی شبیه `https://dakhl-o-kharj.YOUR-SUBDOMAIN.workers.dev`) رو کپی کن.
6. توی فایل `script.js`، خط اول `CONFIG.WORKER_URL` رو با همین آدرس جایگزین کن، و نسخه‌ی جدید فایل رو دوباره توی گیت‌هاب آپلود کن (جایگزین فایل قبلی).

## نحوه‌ی کارکرد همگام‌سازی
- هر کاربر یه «کد همگام‌سازی» ۶ رقمی می‌سازه (از تب تنظیمات).
- با وارد کردن همون کد روی دستگاه دیگه، اطلاعات دو طرف با هم یکی می‌شن.
- کد فقط یه شناسه‌ی ساده برای پیدا کردن داده روی سرورـه، نه رمز عبور — یعنی هرکسی کد رو داشته باشه به همون داده دسترسی داره. برای استفاده‌ی شخصی/خانوادگی کافیه.

## نصب روی گوشی
- آیفون: سافاری → دکمه‌ی اشتراک‌گذاری → Add to Home Screen
- اندروید: کروم → منو → Add to Home screen / Install app
